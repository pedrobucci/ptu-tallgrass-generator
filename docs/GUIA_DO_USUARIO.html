O que o programa faz?

O PTU Encounter Generator sorteia encontros para sessões de Pokémon Tabletop United. Você informa o terreno e a distância percorrida; o programa decide se houve encontro e, quando houver, sorteia Pokémon, nível, sexo, Nature e Shiny.

Primeiro teste recomendado

  1. Envie para o aparelho o arquivo pokemon-yellow-route-1.json.
  2. Importe-o na tela Terrenos.
  3. Abra Percorrer, informe 5 km e toque em PERCORRER.
  4. Repita se nenhum encontro ocorrer — isso é normal e faz parte do sorteio.

Três ideias importantes

  • O programa funciona offline para gerar encontros.
  • Cada terreno é um arquivo de texto no formato JSON.
  • As raridades são pesos relativos; elas não precisam somar 100.

3 · Encontros

Como percorrer um terreno

1Terreno2Distância e unidade3Permitir Shiny4Sortear

Passo a passo

  1. Escolha o terreno.
  2. Digite a distância percorrida.
  3. Escolha metros ou quilômetros.
  4. Decida se Shiny está permitido.
  5. Confira a chance estimada.
  6. Toque em PERCORRER.

O resultado pode ser…

Nenhum encontro: o sorteio não passou na chance calculada. Tente outro percurso.

Um encontro: aparece uma ficha com espécie, nível, sexo, raridade, Nature e possível Shiny.

Importante: cada percurso gera no máximo um encontro.

Para testar rapidamente: use uma distância maior, como 5 km. A distância aumenta a chance acumulada, mas não muda quais Pokémon existem no terreno.

5 · Histórico e ajustes

O que fica salvo?

Histórico

Cada encontro bem-sucedido é armazenado com data, terreno, Pokémon, nível, Nature, chance e indicação de Shiny.

Excluir um terreno não apaga os encontros antigos que já foram registrados.

Dados locais

Terrenos, configurações, histórico, música e imagens em cache ficam no dispositivo. Não é necessário criar conta.

Desinstalar o aplicativo pode apagar esses dados.

Probabilidade de encontro

Cada frequência possui uma chance base por intervalo. Nos valores iniciais:

JSONNa telaChance
uneventfulTranquila5%
rareRara15%
normalNormal30%
frequentFrequente50%
eventfulAgitada75%

Botões de manutenção

  • Limpar cache: remove imagens baixadas; não apaga terrenos.
  • Exportar: salva uma cópia das configurações.
  • Restaurar padrões: volta probabilidades e preferências aos valores iniciais.

6 · JSON sem mistério

Como o arquivo é organizado

JSON é texto com nomes e valores. Chaves { } formam blocos; colchetes [ ] formam listas; textos usam aspas duplas.

arquivo.json
├── schema_version → versão do formato
├── background_image_url → opcional
└── terrain → dados do terreno
    ├── name
    ├── min_lvl / max_lvl
    ├── encounter_frequency
    ├── shiny_rate
    └── pokemon_table [ ]
        ├── Pokémon 1 { }
        ├── Pokémon 2 { }
        └── outros…

Regras de escrita

  • Use aspas duplas: "name".
  • Separe campos com vírgula.
  • Não coloque vírgula depois do último campo.
  • Use ponto em decimais: 0.5, nunca 0,5.
  • true, false e null não usam aspas.

Como salvar

  1. Abra um editor de texto simples.
  2. Cole um modelo válido.
  3. Altere somente os valores necessários.
  4. Salve em UTF-8 com extensão .json.
  5. Importe e leia a prévia antes de confirmar.
No Windows: ao usar o Bloco de Notas, escolha “Todos os arquivos” e escreva o nome completo, por exemplo floresta-viridiana.json. Isso evita salvar acidentalmente como .json.txt.

7 · Modelo pronto

Exemplo: Rota 1 de Pokémon Yellow

Pidgey aparece nos níveis 2–7 e Rattata nos níveis 2–4. As categorias common e unusual aproximam a proporção original de 70% e 30%.

{
  "schema_version": "1.0",
  "terrain": {
    "name": "Pokémon Yellow — Rota 1",
    "min_lvl": 2,
    "max_lvl": 7,
    "encounter_frequency": "normal",
    "shiny_rate": null,
    "pokemon_table": [
      {
        "number": 16,
        "rarity": "common",
        "gender": true,
        "male_odd": null,
        "min_lvl": 2,
        "max_lvl": 7
      },
      {
        "number": 19,
        "rarity": "unusual",
        "gender": true,
        "male_odd": null,
        "min_lvl": 2,
        "max_lvl": 4
      }
    ]
  }
}

Para adicionar um Pokémon

Os colchetes [ ] delimitam a lista. Copie um bloco inteiro entre { }, cole antes do colchete final e use vírgula entre os blocos.

Para criar outra rota

Troque o nome, os níveis gerais e toda a lista pokemon_table. Mantenha schema_version como "1.0".

8 · Campos do terreno

O que cada campo significa

CampoValor aceitoExplicação simples
schema_version"1.0"Versão do formato. Não altere.
background_image_urlURL, null ou omitidoImagem opcional do terreno. Se usada, deve começar com https:// ou http://.
terrain.nameTexto de 1 a 120 caracteresNome exibido no programa. Um nome já existente oferece substituição.
min_lvlInteiro de 0 a 100 ou nullNível mínimo padrão do terreno.
max_lvlInteiro de 0 a 100 ou nullNível máximo padrão. Deve ser igual ou maior que o mínimo.
encounter_frequencyUm dos cinco textos abaixoEscolhe qual chance base dos Ajustes será utilizada.
shiny_rateNúmero entre 0 e 1 ou nullChance própria de Shiny. null usa a chance global.
pokemon_tableLista [ ]Contém um bloco para cada Pokémon possível.

Valores exatos de encounter_frequency

uneventful

Tranquila

rare

Rara

normal

Normal

frequent

Frequente

eventful

Agitada

Use inglês

O JSON exige os textos da esquerda.

Taxa global: escreva "shiny_rate": null, sem aspas em null. Para uma taxa própria, use um decimal entre 0 e 1; por exemplo, 1 em 4.096 é 0.000244140625.

9 · Campos dos Pokémon

Montando a pokemon_table

"pokemon_table": [
  { "number": 25, "rarity": "rare", "gender": true,
    "male_odd": 50, "min_lvl": 4, "max_lvl": 7 },
  { "number": 16, "rarity": "common", "gender": true,
    "male_odd": null, "min_lvl": null, "max_lvl": null }
]

Cada par de chaves { } é um Pokémon; os colchetes [ ] mantêm todos eles na mesma lista.

CampoExemploO que controla
number25Número da National Dex. Pikachu é 25, Pidgey é 16, Rattata é 19.
rarity"rare"Grupo de peso: common, unusual, rare, super_rare ou legendary.
gendertruetrue sorteia sexo conforme a espécie; false desliga esse sorteio para a entrada.
male_odd50 ou nullPercentual de macho. null usa a proporção do catálogo local.
min_lvl4 ou nullNível mínimo específico. null usa o mínimo do terreno.
max_lvl7 ou nullNível máximo específico. null usa o máximo do terreno.

Não repita números

Cada National Dex pode aparecer apenas uma vez no mesmo terreno. Duas entradas com "number": 25 geram erro de validação.

Use o catálogo local

O aplicativo conhece 1.025 espécies-base. Se o número não existir no catálogo, a importação é bloqueada.

Forma regional e variações: o formato atual trabalha pela espécie-base da National Dex. Não invente números para formas alternativas.

10 · Probabilidade

Como as raridades viram chances

Primeiro o programa escolhe uma raridade disponível; depois escolhe um Pokémon dentro dela. Os pesos iniciais somam 100 quando todas as cinco categorias estão presentes.

Raridade no JSONPeso inicialReferência prática
common60Muito comum — aproximadamente 60% quando há uma entrada em cada categoria.
unusual25Incomum.
rare10Raro.
super_rare4Muito raro.
legendary1Excepcional; use somente quando fizer sentido para a mesa.

Exemplo da Rota 1

Apenas common e unusual estão presentes.

Pidgey: 60 ÷ (60 + 25) = 70,6%

Rattata: 25 ÷ (60 + 25) = 29,4%

Isso aproxima os 70% e 30% do jogo.

Dois Pokémon na mesma raridade

Se Pidgey e Spearow forem ambos common, eles dividem igualmente o grupo comum.

O JSON atual não possui um peso numérico individual por Pokémon.

Ordem completa do sorteio

Chance de haver encontro
→
Raridade disponível
→
Pokémon do grupo
→
Nível, sexo, Nature e Shiny
Quer mudar as proporções? Altere os pesos na tela Ajustes. Eles são globais e afetam todos os terrenos. Para valores diferentes por rota, escolha as categorias com cuidado.

12 · Solução de problemas

Erros comuns no JSON

conteúdo não é um JSON válido

Geralmente falta uma vírgula, aspas, chave ou colchete. Compare com o modelo.

schema_version: Invalid input

Use exatamente "1.0", incluindo as aspas.

number: Pokémon não existe

Confira o número da National Dex e não use zero.

está duplicado neste terreno

Remova a segunda entrada com o mesmo número.

intervalo de nível inválido

O mínimo ficou maior que o máximo. Corrija os dois valores.

rarity: Invalid option

Use apenas um dos cinco nomes em inglês mostrados neste guia.

arquivo não aparece no seletor

Confirme a extensão .json ou .mp3 e salve em Downloads.

nenhum Pokémon elegível

A lista está vazia, os números não existem ou os níveis estão inválidos.

Quando a música não toca

  • Confirme que o arquivo realmente é MP3, e não outro formato renomeado.
  • Ative Reproduzir em encontros, aumente o volume e salve.
  • Use Testar depois que aparecer “MP3 armazenado no aplicativo”.
  • A música de encontro toca somente quando um encontro acontece.

Quando os botões de arquivo não abrem

Instale a versão 0.1.1 ou superior. Essa versão usa o seletor nativo do Android para JSON e MP3.

Antes de pedir ajuda: anote o modelo do aparelho, versão do Android, versão do aplicativo, nome do arquivo e a mensagem completa exibida na tela.

13 · Checklist final

Teste antes da sessão

Terreno

  • O JSON foi importado sem erros.
  • O nome e os níveis estão corretos.
  • Todos os Pokémon esperados aparecem.
  • As raridades fazem sentido.
  • O terreno está selecionado.

Aplicativo

  • Um percurso consegue gerar encontro.
  • O resultado aparece no histórico.
  • O MP3 toca no botão Testar.
  • Volume e Shiny estão configurados.
  • O aparelho tem bateria para a sessão.

Segurança no Android

O APK é publicado no GitHub e não vem da Play Store. Durante a instalação pode ser necessário desativar temporariamente o Bloqueador Automático e permitir instalação pelo navegador ou aplicativo usado para baixar o arquivo. Depois de instalar:

  • reative o Bloqueador Automático;
  • desative Depuração USB/sem fio se não estiver usando;
  • remova a permissão “Instalar apps desconhecidos” do aplicativo usado para instalar.

Sobre o projeto

Este aplicativo é uma ferramenta independente, gratuita e de código aberto para grupos de RPG. Não contém ROMs, músicas extraídas de jogos ou imagens copiadas dos jogos.

Pokémon e nomes relacionados pertencem aos respectivos titulares. O projeto não é afiliado, patrocinado ou aprovado pela Nintendo, Creatures Inc. ou The Pokémon Company.

Regra de ouro

Guarde sempre uma cópia do JSON que funcionou. Para criar outro terreno, duplique essa cópia e altere aos poucos, validando antes de usar na sessão.

Atualizações: futuras versões podem ampliar o schema. Enquanto este guia indicar a versão 1.0, mantenha "schema_version": "1.0".
